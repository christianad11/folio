# Folio v0.2.3

A standalone, offline PDF reader for **Apple Silicon Macs (M1 and later)** running **macOS 13 Ventura or newer**.

## Install

Download **Folio-0.2.3-arm64.zip**, unzip it, and move **Folio.app** into **Applications**. Open it and add it to your Dock if you like. No Node.js, Python, running Terminal, or local server is required.

The app is ad-hoc signed and **not notarized by Apple**. macOS may block the first launch. If you trust the download, follow [Apple’s instructions](https://support.apple.com/en-us/102445) to approve it in **System Settings → Privacy & Security → Open Anyway**. Your Mac may require administrator approval.

## Included

- Custom shelves with rename and delete controls. Deleting a shelf keeps its books.
- Drag books into a saved order within each shelf, with keyboard ordering actions too.
- Continuous PDF scrolling, trackpad zoom, editable page numbers, chapters, and search.
- Highlights, bookmarks, notes, passage exports, and portable library backups.
- Multiple PDF import, local safety checks, and approval for PDFs with disabled attachments.
- Correct rendering of large cover images and a short, quiet startup transition.

This release contains an **arm64 build only**. It does not run on Intel Macs, Windows, iPhone, or iPad.

The ZIP includes the complete app and its runtime. Personal PDFs and library data are not included. Titles use a system serif fallback; the optional Michelangelus font is not redistributed.

`SHASUMS256.txt` contains the SHA-256 checksum for the ZIP.
